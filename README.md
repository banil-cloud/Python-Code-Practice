# ❓ Frequently Asked Questions (FAQ)

<details>
  <summary><strong>What is GitHub?</strong></summary>

  GitHub is a code hosting platform for version control and collaboration. It lets you and others work together on projects from anywhere.

</details>

<details>
  <summary><strong>How do I create a repository?</strong></summary>

  1. Go to [GitHub](https://github.com).
  2. Click the "+" icon in the top-right corner.
  3. Choose "New repository".
  4. Enter the repository name and click **Create repository**.

</details>

<details>
  <summary><strong>Can I make my repository private?</strong></summary>

  Yes, during the repository creation, select the **Private** option.

</details>
